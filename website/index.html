Get Dubplate.

Dubplate is free and open source. To build and run it on a Mac, install Git, a current stable Rust toolchain with Cargo, and the Xcode command line tools.

Open a music folder on first launch, or import your rekordbox collection. You’ll need to supply a rekordbox database key for the collection import.

Run from Terminal

git clone https://github.com/lvndry/dubplate.git
cd dubplate
cargo app

The first build takes a few minutes.
